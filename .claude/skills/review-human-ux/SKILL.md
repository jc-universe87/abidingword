# Human-first UX review

Use actual UI, screenshots and task scenarios. Identify primary user, question and success condition. Check initial view, next action, steps and jargon, pending/error/empty states, destructive previews, undo, touch/keyboard, mobile reading and data provenance. Include the fewest concrete changes with the largest effect. Avoid importing another project's surface styling.

Score each dimension with evidence; label unknown until tested with a real view. Seek a non-technical user test where possible.
